# Colonize ($COLONIZE)

AI-powered Mars colonization and autonomous planetary engineering laboratory.

Engineer survival. Build civilization. Colonize Mars.

## What's here

- `index.html`: the full website, including the 3D Mars colony simulator and the Solana connect-wallet button
- `logo.png`, `mark.png`, `overview.jpg`: brand images used by the page

The page is a static site with no build step. three.js (r128) and @solana/web3.js (1.95.3) load from public CDNs.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Deploy with GitHub Pages

1. Push these files to the root of your repository.
2. In the repository, go to Settings > Pages.
3. Under "Build and deployment", choose "Deploy from a branch", then pick `main` and `/ (root)`.

Wallet extensions such as Phantom, Solflare and Backpack connect normally on a standalone page like GitHub Pages.
